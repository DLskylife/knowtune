# 维医样例语料（26 篇）

这些是**普通上传文件**，就放在 `data/uploads/` 下，走标准 `ingest` 流程，没有单独的语料目录、单独的导入脚本或单独的配置。共 26 个文件、约 4.5 MB。

**来源**：新疆维吾尔自治区中医药管理局公开发布的维吾尔医诊疗指南与技术规范（新中医药发〔2025〕2 号 / 3 号），以及若干公开网页转成 Markdown 的条目。逐篇的原文链接、依据文号、sha256 指纹见同目录的 `维医来源清单.md`。

## 三步建出一个能问的知识库

```bash
knowtune kb create 维医知识库                 # 记下返回的 id，例如 1
knowtune ingest data/uploads/weiyi --kb 1     # 递归导入目录内所有 pdf/md
```

然后在后台「站点」弹窗 →「板块与知识库」，把 `med`（维医问答）绑到这个库 id。前台站点就能问了。

`维医来源清单.md` 也会被一起导入（它是来源说明，内容是链接表格）。不希望它进索引，导入前把它移到目录外即可。

> `knowtune ingest <目录>` 会 `rglob` 递归找支持格式的文件；系统按 `data/uploads/` 内的路径管理这些文档，删除文档时会按上传文件的语义处理。本目录只放行 `*.pdf` / `*.md` 进版本库，`data/uploads/` 下其他本机上传文件仍被 `.gitignore` 排除——别把私有资料放进这个目录。
