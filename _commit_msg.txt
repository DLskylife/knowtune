回答不再死板：前端吃 Markdown + 提示词改成"讲清楚"而不是"罗列条目"

截图里三件事叠在一起：
1. `**使用硝石**` 原样漏出——renderBody 只处理代码和引注，不认粗体/列表，
   模型给的分点结构全被压成一行行加星号的纯文本。
2. 回答是资料条目的机械拼接：每味药一句"治XX"，不解释怎么用、适合谁。
3. "肚子疼"配了治咳嗽的桔梗——检索回来的块没筛，模型硬凑。
另外默认 temperature=0.1，7B 这一档的输出高度模板化。

前端（app.js / style.css）
- 新增 inlineMd + mdBlocks：粗体、有序/无序列表、标题、引用块、行内代码、引注。
  行内代码先抽占位符再处理，避免代码里的 ** 被当粗体；孤立的单星号不配对，
  不会被贪婪匹配吞掉整段（古籍资料里乱码星号很常见）。
- 气泡里补 ul/ol/li/strong/h3-5 样式，列表项之间留 6px，行号不再和药名挤一起。

提示词（qa_v1.md / qa_ug.md 同步）
- 新增「回答方式」：先一句话直答并把口语对到规范病名 → 整合成 2-4 点，
  每点写清「用什么 → 治什么 → 怎么用 → 适合什么情况」→ 结尾一句前提/提醒。
- 明确"只取与问题直接相关的内容，不拿治别的病的方子凑数"，否则按"未找到"回答。
- 明确禁止"以上方法可根据具体情况选择使用"这类零信息收尾。
- 篇幅要求 150-350 字（资料丰富可到 500），别再三条短句打发。
- 允许 Markdown 分点，但禁止整段加粗与代码块。

参数
- generation.temperature 0.1 → 0.3（config.py 与 default.yaml 同步）；
  config.py 里 max_tokens 还停在 1024，与 default.yaml 的 3072 漂移，一并修正。
